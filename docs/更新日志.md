# 更新日志

## v0.3.3 — 首个对外测试版本

这是本应用的第一个公开测试版本，Windows 端的核心功能已经可用，欢迎试用并反馈。

它的用途是**让上游弹幕 API 项目 [`huangxd-/danmu_api`](https://github.com/huangxd-/danmu_api)
在 Windows 上本地跑起来**：核心仍由你自己在应用内安装，应用负责装、配、启停和看护。

### 核心管理

- 在应用内从 GitHub 安装弹幕核心：稳定核心（上游 `huangxd-/danmu_api`）与自定义核心（任意仓库 + 分支）。
- 版本探索：查看提交历史、按指定提交安装、把 PR 装成自定义实验核心。
- 本地版本历史：保留最近几个版本，一键回退，无需重新下载。
- 切换分支：分支列表点开即刷新，选好目标分支后一键切换并重装。
- 检查更新：发现新版本可以直接在提示里选择"立即更新"，也可以稍后再应用；
  更新完成后不再残留"有新版本"的提示。

### 配置与运行

- 配置工作台：变量清单来自当前核心自带的 `configs/envs.js`，换核心自动跟着变；
  按类型生成对应控件（开关、下拉、多选、列表、映射表等），支持搜索与按状态筛选；
  每个变量标注当前值的来源（进程环境 / `.env` / 核心默认），敏感值默认打码。
- 保存即生效：写入 `config\.env`，核心热重载，不需要重启服务。
- 服务看护：启动 / 停止 / 重启、健康检查、异常退出时展示核心日志尾部，
  停止时确保进程与端口都不残留。
- 运行状态带：直观显示运行环境、核心依赖、可选 Redis 与 GitHub 接口配额。

### 桌面集成

- 托盘菜单、开机自启（后台静默启动）、单实例运行。
- 关闭窗口行为可选：询问 / 退出 / 最小化到托盘。
- Windows 原生通知，可分别控制"更新与依赖提醒""自启成功"等类别。
- 局域网访问的防火墙授权引导。

### 工具

- 日志查看、API 接口调试、弹幕下载与导出、缓存管理、请求记录。
- 数据备份与恢复，支持导出到本地或同步到 WebDAV。
- GitHub 线路测速与切换，可配置 GitHub Token 提高接口配额。

### 软件更新

- 内置带签名的软件更新通道，可在应用内检查、下载并更新本应用。
- 支持关闭自动检查、跳过指定版本。

### 已知限制

- 仅提供 **Windows x64**，要求 Windows 10 19041（20H1）及以上；暂不支持 32 位与 ARM64。
- 使用项目自签名证书，安装时可能提示"未知发布者"/SmartScreen 警告。
- 界面目前只有简体中文。
- 首次启动需要准备运行环境（约 10–30 秒，视磁盘与杀毒软件而定），仅需一次。
- 自定义核心与 PR 实验版本未经稳定版校验，建议用「本地版本历史」随时回退。
