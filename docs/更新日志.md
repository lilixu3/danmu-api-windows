# 更新日志

## v0.3.5 — 配置工作台交互修正（测试版）

这一版把 0.3.4 配置页里几处不好用的地方按反馈改掉，仍然只动界面。

### 变量列表

- **每一行恢复「编辑」和「清除」两个按钮**：编辑打开对应类型的编辑弹窗，
  清除调用核心的删除接口把该变量从 `.env` 里移除、恢复核心默认值。
  两个按钮等宽、在所有行上对齐成同一列。
- **未配置的变量上「清除」是灰的**：没有显式配置可清，按钮不发请求。
- **行内直接显示当前值**：变量名下面加了一个值框，超长的值默认折叠成两行，
  右侧有「展开 / 收起」自己控制，不用先点进编辑弹窗才知道现在是什么值。
- 已配置的行只显示「已配置」一个标签，不再同时挂 `.env` 来源标签。

### 搜索

- 搜索时在列表上方明确提示「以下是包含『关键词』的全部变量（在所有分类中搜索，共 N 个）」。
- 搜索框右侧新增「清空关键词」按钮，一键回到当前分类的完整列表。

### 编辑弹窗

- 弹窗底部**只保留「取消」和「保存」**，去掉原来的「恢复默认」和「清空」——
  这两个动作已经由列表行上的「清除」按钮承担，同一个动作不再出现在两处。

### 其他

- 修复浅色主题下把鼠标移到左侧分类上时，选中底色发黑、分类标题看不清的问题。

## v0.3.4 — 配置工作台改版（测试版）

这一版只动界面，不动协议、不动核心、不改你的任何配置。

### 配置工作台

- **三栏布局**：左边选分类、中间选变量、右边看详情。窗口变窄时自动收成两栏、再收成单栏，
  不用横向滚动。
- **变量列表改为虚拟化**：变量很多的核心（几百个变量）滚动不再卡顿。
- **右侧详情面板**：选中变量后可以直接看到它的类型、当前值来源（进程环境 / `.env` / 核心默认）
  和说明，再决定是「编辑」还是「恢复默认」——以前这两个按钮长得一模一样，容易点错，
  现在「恢复默认」是红色危险样式，且未配置的变量上它是灰的。
- 搜索框不再固定 250px 宽，窄窗口下不再把标题挤成两行。

### 界面一致性

- 新增一层全应用共用的「外壳词汇」（标题、卡片、胶囊、状态色、输入框等），
  配置页是第一个迁移到这套词汇的页面；**其余页面外观保持原样**，本轮用逐帧渲染比对确认过。

### 已知限制

- 只有配置页迁移到了新词汇，其他页面仍是旧样式；后续会按页面逐步迁移。
- 界面重构不改变任何协议行为：`.env` 写入、核心安装更新、服务启停逻辑完全未动。

## v0.3.3 — 首个对外测试版本

这是本应用的第一个公开测试版本，Windows 端的核心功能已经可用，欢迎试用并反馈。

它的用途是**让上游弹幕 API 项目 [`huangxd-/danmu_api`](https://github.com/huangxd-/danmu_api)
在 Windows 上本地跑起来**：核心仍由你自己在应用内安装，应用负责装、配、启停和看护。

### 核心管理

- 在应用内从 GitHub 安装弹幕核心：稳定核心（上游 `huangxd-/danmu_api`）与自定义核心（任意仓库 + 分支）。
- 版本探索：查看提交历史、按指定提交安装、把 PR 装成自定义实验核心。
- 本地版本历史：保留最近几个版本，一键回退，无需重新下载。
- 切换分支：分支列表点开即刷新，选好目标分支后一键切换并重装。
- 检查更新：发现新版本可以直接在提示里选择"立即更新"，也可以稍后再应用；
  更新完成后不再残留"有新版本"的提示。

### 配置与运行

- 配置工作台：变量清单来自当前核心自带的 `configs/envs.js`，换核心自动跟着变；
  按类型生成对应控件（开关、下拉、多选、列表、映射表等），支持搜索与按状态筛选；
  每个变量标注当前值的来源（进程环境 / `.env` / 核心默认），敏感值默认打码。
- 保存即生效：写入 `config\.env`，核心热重载，不需要重启服务。
- 服务看护：启动 / 停止 / 重启、健康检查、异常退出时展示核心日志尾部，
  停止时确保进程与端口都不残留。
- 运行状态带：直观显示运行环境、核心依赖、可选 Redis 与 GitHub 接口配额。

### 桌面集成

- 托盘菜单、开机自启（后台静默启动）、单实例运行。
- 关闭窗口行为可选：询问 / 退出 / 最小化到托盘。
- Windows 原生通知，可分别控制"更新与依赖提醒""自启成功"等类别。
- 局域网访问的防火墙授权引导。

### 工具

- 日志查看、API 接口调试、弹幕下载与导出、缓存管理、请求记录。
- 数据备份与恢复，支持导出到本地或同步到 WebDAV。
- GitHub 线路测速与切换，可配置 GitHub Token 提高接口配额。

### 软件更新

- 内置带签名的软件更新通道，可在应用内检查、下载并更新本应用。
- 支持关闭自动检查、跳过指定版本。

### 已知限制

- 仅提供 **Windows x64**，要求 Windows 10 19041（20H1）及以上；暂不支持 32 位与 ARM64。
- 使用项目自签名证书，安装时可能提示"未知发布者"/SmartScreen 警告。
- 界面目前只有简体中文。
- 首次启动需要准备运行环境（约 10–30 秒，视磁盘与杀毒软件而定），仅需一次。
- 自定义核心与 PR 实验版本未经稳定版校验，建议用「本地版本历史」随时回退。
